Falta conectar Supabase

Configuralo una sola vez para que la app tenga login y sincronice.

  1. Creá una cuenta gratis en supabase.com y un proyecto nuevo.
  2. En SQL Editor pegá y ejecutá el archivo supabase-setup.sql.
  3. En Authentication → Sign In / Providers → Email, desactivá Confirm email.
  4. En Project Settings → API copiá Project URL y anon public key.
  5. Pegalas arriba de este archivo, en SUPABASE_URL y SUPABASE_ANON_KEY.
